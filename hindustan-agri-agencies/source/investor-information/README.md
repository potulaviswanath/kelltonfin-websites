# HAPL Investor Information — Source Development Copy

This folder is the separated source-code version of the custom Elementor HTML widget used on:

`/investor-information-new/`

## Files

- `index.html` — page markup/content
- `style.css` — custom HAPL dashboard CSS
- `script.js` — category-switching JavaScript

## Relationship to WordPress / Elementor

The live WordPress page currently contains the combined HTML + CSS + JavaScript inside an Elementor HTML widget.

These files are the **master development/source copy** we can edit in VS Code and version in Git.

When changes are approved, the final combined code can be placed back into the Elementor HTML widget.

## Important

Do not delete the existing Elementor XML backup. It remains the WordPress/Elementor recovery copy.

This source folder is a development/version-control copy; it is not automatically connected to the live website.
